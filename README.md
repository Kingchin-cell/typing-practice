# ⌨️ 打字练习 (Typing Practice)

一个纯前端的打字练习网站，双击即用、无需安装、完全离线。支持中文、英文、名著三种练习模式，以及计时挑战与无尽练习。

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 🀄 中文模式 | 433 条人民日报风格金句，伪随机洗牌队列抽取，一轮内不重复 |
| 🇬🇧 英文模式 | 10,000 句英文语料（名人名言 + 自然句） |
| 📚 名著模式 | 10 部经典作品全文，按顺序逐段练习，支持切换作品 |
| ⏱️ 三种时长 | 60 秒 / 120 秒倒计时，或无尽模式想练多久练多久 |
| 🎯 实时反馈 | 打错的字立即标红，支持退格修正；速度、正确率、进度实时统计 |
| 🌙 跟随系统主题 | 自动适配深色 / 浅色模式 |
| 🖱️ 输入法候选框跟随光标 | 中文输入时候选框始终出现在当前字符正下方，视线不用来回切换 |

## 🚀 快速开始

无需安装任何依赖，用浏览器打开即可：

```bash
# 方式一：直接双击 index.html
# 方式二：启动本地静态服务器（可选）
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

推荐使用 Chrome / Edge 等现代浏览器。

## 🔧 技术实现

- **纯原生 HTML / CSS / JavaScript**：零依赖、零构建、无后端，全部静态资源本地运行
- **自绘字符渲染**：文本区由一个个 `<span>` 字符组成，支持逐字着色（正确绿 / 错误红 / 光标闪烁）
- **隐藏输入框收集输入法信号**：中文输入法依赖原生 `<input>`/`<textarea>`，页面用透明输入框接收上屏文字后与目标文本逐字比对
- **`syncGhostPosition()` — 候选框跟随光标**：每次光标移动时读取当前待打字符的 `getBoundingClientRect()`，把隐藏输入框动态定位到该字符正下方，从而让输入法候选框始终跟随打字位置
- **Fisher-Yates 洗牌队列**：中文语料先整体洗牌再顺序抽取，实现"伪随机、一轮内不重复"
- **CSS 变量 + `prefers-color-scheme`**：零 JS 实现深浅色主题自动切换
